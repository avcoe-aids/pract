
# Tic-Tac-Toe using Reinforcement Learning (Q-Learning)

import random

# 1. Create Environment
board = [" "] * 9

# Q-table
Q = {}

# Get state of board
def get_state(board):
    return "".join(board)


# 2. Define Tic-Tac-Toe Game
def show_board(board):
    print()
    print(board[0], "|", board[1], "|", board[2])
    print("--+---+--")
    print(board[3], "|", board[4], "|", board[5])
    print("--+---+--")
    print(board[6], "|", board[7], "|", board[8])


def check_winner(board):
    wins = [
        (0, 1, 2), (3, 4, 5), (6, 7, 8),
        (0, 3, 6), (1, 4, 7), (2, 5, 8),
        (0, 4, 8), (2, 4, 6)
    ]

    for a, b, c in wins:
        if board[a] != " " and board[a] == board[b] == board[c]:
            return board[a]

    if " " not in board:
        return "Draw"

    return None


# 3. Build Reinforcement Learning Model
def choose_action(board, epsilon=0.1):
    state = get_state(board)

    if state not in Q:
        Q[state] = [0] * 9

    available = [i for i in range(9) if board[i] == " "]

    # Exploration
    if random.random() < epsilon:
        return random.choice(available)

    # Exploitation
    return max(available, key=lambda x: Q[state][x])


# 4. Train the Model
def train(episodes=5000):

    for episode in range(episodes):
        board = [" "] * 9

        while True:
            state = get_state(board)

            # AI move
            action = choose_action(board)
            board[action] = "X"

            result = check_winner(board)

            if result == "X":
                Q[state][action] += 1
                break

            if result == "Draw":
                Q[state][action] += 0.5
                break

            # Random opponent move
            available = [i for i in range(9) if board[i] == " "]
            opponent = random.choice(available)
            board[opponent] = "O"

            result = check_winner(board)

            if result == "O":
                Q[state][action] -= 1
                break

            if result == "Draw":
                Q[state][action] += 0.5
                break

            new_state = get_state(board)

            if new_state not in Q:
                Q[new_state] = [0] * 9

            # Q-learning update
            alpha = 0.1
            gamma = 0.9

            Q[state][action] += alpha * (
                gamma * max(Q[new_state]) - Q[state][action]
            )

    print("Training completed!")


# 5. Test the Model
def play_game():

    board = [" "] * 9

    print("\nTic-Tac-Toe")
    print("Positions are:")
    print("0 | 1 | 2")
    print("--+---+--")
    print("3 | 4 | 5")
    print("--+---+--")
    print("6 | 7 | 8")

    while True:

        # AI move
        action = choose_action(board, epsilon=0)
        board[action] = "X"

        print("\nAI Move:")
        show_board(board)

        result = check_winner(board)

        if result:
            print("Result:", result)
            break

        # Human move
        while True:
            try:
                move = int(input("Enter your move (0-8): "))

                if move < 0 or move > 8:
                    print("Please enter a number between 0 and 8.")
                elif board[move] != " ":
                    print("Invalid move! Position already occupied.")
                else:
                    break

            except ValueError:
                print("Please enter a valid number.")

        board[move] = "O"

        result = check_winner(board)

        if result:
            show_board(board)
            print("Result:", result)
            break


# 6. Train and Test
train(5000)
play_game()

































What is Reinforcement Learning?

Reinforcement Learning (RL) is a type of machine learning in which an agent learns by interacting with an environment and receiving rewards or penalties for its actions.

In this practical:
- AI is the Agent.
- Tic-Tac-Toe board is the Environment.
- AI moves are the Actions.
- Winning, losing and drawing provide Rewards.
What is Q-Learning?

Q-Learning is a model-free reinforcement learning algorithm that learns which action is best in a particular state by storing values in a Q-table.
Important terms
Term	Meaning
Agent	AI player
Environment	Tic-Tac-Toe game board
State	Current position of the board
Action	Move selected by AI
Reward	Positive or negative feedback
Q-table	Stores values of actions for each state
Exploration	Trying random actions
Exploitation	Choosing the best-known action
Learning Rate (Alpha)	Controls how much new information is learned
Discount Factor (Gamma)	Determines importance of future rewards
Episode	One complete training game

if random.random() < epsilon:    return random.choice(available)



Exploration: AI tries a random move to discover new possibilities.
return max(available, key=lambda x: Q[state][x])



Exploitation: AI selects the move with the highest learned Q-value.

In this practical, epsilon = 0.1 by default.
- 10% chance of exploration.

D. Rewards and penalties
Game result	Reward
AI wins	+1
AI draws	+0.5
AI loses	-1

These values help AI learn which actions are beneficial.
E. Q-Learning formula
\[
Q(s,a)\leftarrow Q(s,a)+
\alpha[r+\gamma\max Q(s',a')-Q(s,a)]
\]

Where:
Symbol	Meaning
Q(s,a)	Current Q-value
α (Alpha)	Learning rate
r	Immediate reward
γ (Gamma)	Discount factor
s	Current state
s'	Next state
max Q	Best future Q-value

In your program:
- Alpha = 0.1
- Gamma = 0.9
- Episodes = 5000

8. Important technical point about your code
Your program is a simplified Q-learning implementation. It updates the Q-value after the AI's move, using the next board state after the opponent's move.

However, it does not explicitly model the opponent's move as part of the Q-learning transition or update all previous moves at the end of an episode. Therefore, it may not learn a perfect Tic-Tac-Toe strategy
