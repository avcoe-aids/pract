# Data Visualization using Matplotlib
# Air Quality Index (AQI) Analysis

import pandas as pd
import matplotlib.pyplot as plt

# 1. Load Dataset
data = pd.read_csv("city_day.csv")

print("First 5 Rows:")
print(data.head())

# 2. Explore Dataset
print("\nShape:", data.shape)

print("\nColumns:")
print(data.columns)

print("\nNull Values:")
print(data.isnull().sum())

# 3. Select relevant variables
data["Date"] = pd.to_datetime(data["Date"])

# Select one city
data = data[data["City"] == "Delhi"]

# Remove rows where AQI is missing
data = data.dropna(subset=["AQI"])

# 4. AQI Trend over Time
plt.figure(figsize=(10, 5))

plt.plot(data["Date"], data["AQI"])

plt.xlabel("Date")
plt.ylabel("AQI")
plt.title("AQI Trend Over Time")
plt.xticks(rotation=45)
plt.show()

# 5. Pollutant Trends

plt.figure(figsize=(10, 5))

plt.plot(data["Date"], data["PM2.5"], label="PM2.5")
plt.plot(data["Date"], data["PM10"], label="PM10")
plt.plot(data["Date"], data["CO"], label="CO")

plt.xlabel("Date")
plt.ylabel("Pollutant Level")
plt.title("Pollutant Trends Over Time")
plt.legend()
plt.xticks(rotation=45)
plt.show()

# 6. Bar Plot - AQI by Month

data["Month"] = data["Date"].dt.month

monthly_aqi = data.groupby("Month")["AQI"].mean()

plt.bar(monthly_aqi.index, monthly_aqi.values)

plt.xlabel("Month")
plt.ylabel("Average AQI")
plt.title("Average AQI by Month")
plt.show()

# 7. Box Plot - AQI Distribution

plt.boxplot(data["AQI"])

plt.ylabel("AQI")
plt.title("AQI Distribution")
plt.show()

# 8. Scatter Plot - AQI vs PM2.5

plt.scatter(data["PM2.5"], data["AQI"])

plt.xlabel("PM2.5")
plt.ylabel("AQI")
plt.title("AQI vs PM2.5")
plt.show()

# 9. Correlation

print("\nCorrelation:")
print(data[["PM2.5", "PM10", "CO", "AQI"]].corr())

plt.imshow(
    data[["PM2.5", "PM10", "CO", "AQI"]].corr(),
    cmap="coolwarm"
)

plt.colorbar()
plt.xticks(range(4), ["PM2.5", "PM10", "CO", "AQI"])
plt.yticks(range(4), ["PM2.5", "PM10", "CO", "AQI"])

plt.title("AQI and Pollutant Correlation")
plt.show()

































What is AQI?
AQI stands for Air Quality Index.

It is a measurement used to indicate how clean or polluted the air is and how it may affect human health.
- Higher AQI means more air pollution.
- Lower AQI means cleaner air.
What is Data Visualization?
Data visualization means representing information using graphs and charts so that data can be understood easily.
What is Matplotlib?
Matplotlib is a Python library used to create graphs such as line charts, bar charts, scatter plots, and box plots.
Important libraries
Library	Purpose
Pandas	Loading and processing datasets.
Matplotlib	Creating graphs and charts.

3. Important pollutants
Pollutant	Meaning
PM2.5	Fine particles with diameter 2.5 micrometres or smaller.
PM10	Particles with diameter 10 micrometres or smaller.
CO	Carbon Monoxide.
AQI	Air Quality Index.

Remember: PM2.5 and PM10 are particulate matter, while CO is a gaseous pollutant.

10. Tricky viva points
1. Why is only AQI missing data removed?
Because AQI is the main variable being analyzed. Other pollutant columns may still contain missing values.

2. What is the difference between a line plot and a scatter plot?
A line plot connects points to show trends, while a scatter plot displays individual points to show relationships.

3. Does the program compare multiple cities?
No. It selects only Delhi.

4. What is the difference between a bar plot and a box plot?
A bar plot compares values across categories, while a box plot summarizes a numerical distribution.

5. Why do we use correlation?
To understand how pollutant measurements are associated with AQI and with each other.

One important improvement: The pollutant line plot and correlation analysis may contain missing values in PM2.5, PM10, or CO. You can use dropna(subset=["PM2.5", "PM10", "CO", "AQI"]) on a separate copy of the data before those analyses to avoid incomplete observations.
