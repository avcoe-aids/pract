# K-Means Clustering on Iris Dataset

import pandas as pd
import matplotlib.pyplot as plt
from sklearn.cluster import KMeans

# 1. Load Dataset
data = pd.read_csv("iris.csv")

print("First 5 rows:")
print(data.head())

# 2. Select Features
# Select SepalLength, SepalWidth, PetalLength, PetalWidth
X = data.iloc[:, 1:5]

print("\nFeatures:")
print(X.head())

# 3. Elbow Method
wcss = []

for i in range(1, 11):
    kmeans = KMeans(n_clusters=i, random_state=42, n_init=10)
    kmeans.fit(X)
    wcss.append(kmeans.inertia_)

# Plot Elbow Graph
plt.plot(range(1, 11), wcss, marker="o")
plt.xlabel("Number of Clusters")
plt.ylabel("WCSS")
plt.title("Elbow Method")
plt.show()

# 4. Apply K-Means
# From the elbow graph, number of clusters = 3
kmeans = KMeans(n_clusters=3, random_state=42, n_init=10)

data["Cluster"] = kmeans.fit_predict(X)

print("\nClustered Data:")
print(data.head(10))

# 5. Visualize Clusters
plt.scatter(
    X.iloc[:, 0],
    X.iloc[:, 1],
    c=data["Cluster"],
    cmap="viridis"
)

plt.xlabel("Sepal Length")
plt.ylabel("Sepal Width")
plt.title("K-Means Clustering")
plt.show()

































What is K-Means Clustering?

K-Means is an unsupervised machine learning algorithm used to divide data into groups called clusters based on similarities between data points.

In this practical, we group Iris flowers into 3 clusters based on their measurements.

Why do we use K-Means?
- To group similar data points.
- To identify patterns in datasets.
- To divide data into clusters.
- To analyze data without predefined labels.
Important terms
Term	Meaning
Clustering	Grouping similar data points
Cluster	A group of similar data points
Centroid	Center point of a cluster
K	Number of clusters
WCSS	Within-Cluster Sum of Squares
Elbow Method	Technique to find the optimal number of clusters
Inertia	Sum of squared distances from points to their nearest centroid

5. Important concepts
A. Iris Dataset

The Iris dataset contains measurements of three types of Iris flowers.

It contains four important features:
1. Sepal Length
2. Sepal Width
3. Petal Length
4. Petal Width
The standard Iris dataset contains 150 samples and 3 flower species.

B. Elbow Method

The Elbow Method helps us find the optimal number of clusters.
- First, we calculate WCSS for K values from 1 to 10.
- Then we plot the WCSS values.
- We identify the point where the decrease in WCSS starts becoming slower.
- This point looks like an elbow.
- In this practical, we choose K = 3.

C. What is WCSS?

WCSS stands for Within-Cluster Sum of Squares.

It measures the sum of squared distances between data points and their nearest cluster centroid.
- Lower WCSS means points are closer to their cluster centers.
- WCSS generally decreases when the number of clusters increases.
