# Sales Data Analysis using CSV, Excel and JSON
import pandas as pd
import matplotlib.pyplot as plt

# 1. Load CSV file
csv_data = pd.read_csv("Superstore.csv", encoding="latin1")

# Create Excel and JSON files from the CSV data
csv_data.to_excel("Superstore.xlsx", index=False)
csv_data.to_json("Superstore.json", orient="records")

# Load data from all three formats
csv_data = pd.read_csv("Superstore.csv", encoding="latin1")
excel_data = pd.read_excel("Superstore.xlsx")
json_data = pd.read_json("Superstore.json")

print("CSV Data:")
print(csv_data.head())

print("\nExcel Data:")
print(excel_data.head())

print("\nJSON Data:")
print(json_data.head())

# 2. Check data
print("\nNull Values:")
print(csv_data.isnull().sum())

print("\nDuplicates:")
print(csv_data.duplicated().sum())

# 3. Data Cleaning
data = csv_data.dropna()
data = data.drop_duplicates()

# 4. Data Transformation
data["Order Date"] = pd.to_datetime(data["Order Date"])

data["Profit %"] = (data["Profit"] / data["Sales"]) * 100

# 5. Data Analysis
print("\nTotal Sales:", data["Sales"].sum())
print("Average Sales:", data["Sales"].mean())
print("Total Profit:", data["Profit"].sum())

print("\nSales by Category:")
print(data.groupby("Category")["Sales"].sum())

# 6. Visualization

# Bar Chart
data.groupby("Category")["Sales"].sum().plot(kind="bar")

plt.title("Sales by Category")
plt.xlabel("Category")
plt.ylabel("Sales")
plt.show()

# Pie Chart
data["Category"].value_counts().plot(
    kind="pie",
    autopct="%1.1f%%"
)

plt.title("Category Distribution")
plt.ylabel("")
plt.show()

# Box Plot
plt.boxplot(data["Sales"])

plt.title("Sales Distribution")
plt.ylabel("Sales")
plt.show()

































What is data analysis?

Excel	Spreadsheet format	Stores data in worksheets with rows and columns.
JSON	JavaScript Object Notation	Stores data in key-value format.

4. Code explanation step by step
Step 1: Import libraries
import pandas as pdimport matplotlib.pyplot as plt



- pandas: Used for data analysis.
- matplotlib.pyplot: Used for data visualization.
- pd and plt are short names (aliases).
Step 2: Load CSV and create other files
csv_data = pd.read_csv("Superstore.csv", encoding="latin1")csv_data.to_excel("Superstore.xlsx", index=False)csv_data.to_json("Superstore.json", orient="records")



- read_csv() reads the CSV file.
- encoding="latin1" helps read certain special characters in the dataset.
- to_excel() converts CSV data into Excel format.
- to_json() converts CSV data into JSON format.
- index=False prevents Pandas from adding an extra index column to the Excel file.
- orient="records" stores each row as a separate JSON object.
Important: Superstore.csv must be present in the current working folder.
Step 3: Load data from all three formats
csv_data = pd.read_csv("Superstore.csv", encoding="latin1")excel_data = pd.read_excel("Superstore.xlsx")json_data = pd.read_json("Superstore.json")



This loads the same sales dataset from three different file formats.
print(csv_data.head())print(excel_data.head())print(json_data.head())



- head() displays the first five rows by default.
- print() displays the data in the output.
Step 4: Check missing values and duplicates
print(csv_data.isnull().sum())print(csv_data.duplicated().sum())



Function	Purpose
isnull()	Checks missing values.
sum()	Counts missing values in each column.
duplicated()	Identifies duplicate rows.
sum()	Counts duplicate rows.

Step 5: Data cleaning
data = csv_data.dropna()data = data.drop_duplicates()



- dropna() removes rows containing missing values.
- drop_duplicates() removes repeated rows.
- Cleaned data is stored in the variable data.
Step 6: Data transformation
data["Order Date"] = pd.to_datetime(data["Order Date"])data["Profit %"] = (data["Profit"] / data["Sales"]) * 100



- pd.to_datetime() converts the Order Date column into date format.
- Profit percentage is calculated using profit and sales.
Formula:
\[
Profit\%=\frac{Profit}{Sales}\times100
\]

Step 7: Data analysis
print(data["Sales"].sum())print(data["Sales"].mean())print(data["Profit"].sum())



Function	Meaning
sum()	Calculates total.
mean()	Calculates average.
groupby()	Groups data based on a column.

data.groupby("Category")["Sales"].sum()



This groups products by category and calculates total sales for each category.

For example, categories may include Furniture, Office Supplies, and Technology.
